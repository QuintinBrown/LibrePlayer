# LibrePlayer
FOSS music player.  
Can scan a folder then extract metadata and add to a sqlite database.  
UI is controlled via JavaFX webview using locally hosted html, css, and js files.  
Repo for themes in progress.  
Runs only in portable mode at the moment.  
Capable of playing mp3, flac, wav, ogg, opus, m4a, aac, and alac files.


<!-- GETTING STARTED -->
## Getting Started

### Installation
1. Download the latest .rar file in the releases section.
2. Extract to the drive of your choice.
3. Run the executable.
4. Click the cogwheel in the top right to import a folder containing your music, you can specify multiple folders by doing this another time.
